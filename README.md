# Lereng Coffee Roasters — WooCommerce store build

A complete WooCommerce store for **Lereng**, a fictional Indonesian specialty coffee roaster in Bali: a custom block theme and one plugin (`lereng-commerce`) covering the flows a real Indonesian coffee shop needs. There are no paid extensions: subscriptions, bundles, gift cards, wholesale and the local payment gateways are all built in.

**▶ Live demo: [open the store in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fgeffaa.github.io%2Flereng-woocommerce%2Fdemo%2Fblueprint.json)**: real WordPress + WooCommerce, running in your browser (first load takes about a minute). Admin: `admin` / `password`. Payments are sandboxed, and every email lands in the **Demo inbox**.

Project page: [geffaa.github.io/lereng-woocommerce](https://geffaa.github.io/lereng-woocommerce/)

## What's in it

| Area | Flows |
|---|---|
| **Catalogue** | 66 products: 38 coffees with 550+ variations (size × grind), single origins, blends, micro-lots, a pre-order, drip bags, cold brew, equipment, merch. Filters by process, roast, origin and taste; coffee facts (producer, altitude, varietals, cupping score), brew recipe and farm story |
| **Checkout** | Block checkout. Delivery rates by province and weight (JNE, SiCepat, GoSend same day), free delivery thresholds, pickup at the roastery, a cold-chain rule for cold brew. Extra fields: courier notes, tax invoice with NPWP validation, gift note. PPN 11% included, IDR |
| **Payments** | Sandbox **QRIS** (EMVCo payload, CRC16) and **virtual accounts** (BCA, Mandiri, BNI, BRI), modelled on Midtrans: payment page with QR and countdown, signed webhook (SHA-512 signature), expiry that cancels the order and returns the stock, refunds |
| **Promotions** | First-order coupon, minimum-spend codes, **gift cards** (scheduled delivery, balance ledger, partial redemption), **Discovery Box** (pick 3, 15% off) and fixed bundles with component stock |
| **Subscriptions** | Subscribe & save without a plugin: every 1, 2 or 4 weeks, renewal orders created before roast day, payment link by email. Customers skip, pause, change coffee/size/grind or cancel; MRR in the admin |
| **After purchase** | Roast days (Mon/Thu, 10:00 cut-off) → roast list with green-coffee weights → bulk "roasting" → ship with waybill → tracking page → delivered → review request. Invoices with DPP/PPN. Restock alerts, wishlist |
| **Wholesale** | Application form → staff approval → wholesale role with tiered prices (25%/30%), 5 kg minimum, quick-order page, invoice payment (bank transfer) |
| **Languages** | English and **Bahasa Indonesia** per visitor: the interface, pages, product copy, attribute terms and tasting notes, using WordPress/WooCommerce's official language packs for core strings. Orders remember their language, so later emails reach the customer in it |
| **Data** | A year of history: 320 customers, 1,100+ orders with seasonality (Ramadan, December), subscriptions, reviews, gift cards, wholesale cafés, imported into WooCommerce Analytics |

## Stack

- WordPress 7.0, WooCommerce 11.2 (HPOS, block cart/checkout, product-collection and product-filters blocks), PHP 8.3
- `wp-content/themes/lereng`: block theme (theme.json, templates, patterns)
- `wp-content/plugins/lereng-commerce`: PSR-4 plugin, one module per area (`src/`), PHPUnit tests for the pure logic (rates, roast schedule, QRIS, signatures, VA numbers, bundle pricing, gift-card codes, subscription schedule, tracking)
- Development runs on **WordPress Playground CLI** (no PHP/MySQL/Docker install): `npm run setup`, `npm run dev`, `npm run seed`
- `scripts/e2e.mjs`: Puppeteer end-to-end checks of every flow above

## Running it

```bash
npm install
npm run setup                 # WordPress + WooCommerce 11.2.1 + Indonesian language packs into .wp/site
npm run seed                  # catalogue, shipping, payments, pages, images, translations
node scripts/wp.mjs seed history   # a year of customers and orders
node scripts/wp.mjs seed analytics # import them into WooCommerce Analytics
npm run dev                   # http://127.0.0.1:9400 (admin / password)
npm test && npm run e2e
node scripts/demo.mjs         # rebuild the Playground demo in docs/demo
```

## Honest notes

- Lereng is fictional. Origins, processes and varieties are real Indonesian coffee; producers and the roastery are invented.
- Payments are a sandbox modelled on Midtrans' API (signature, statuses, VA/QRIS formats). A live store would swap in the Midtrans or Xendit plugin; the order flow stays the same.
- Courier tracking is simulated (checkpoints generated from the waybill); a live store would call the courier or an aggregator API.
- Product photos are CC0 from Wikimedia Commons (credits in `design/photos/CREDITS.md`); labels are generated by `design/build.mjs`.
- In the Playground demo, background jobs (payment expiry, renewals, review emails) run on page views, because PHP in the browser can't make loopback requests.
